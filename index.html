    02 / How it runs

    Four stations. A lead only moves on if the last one signs off.

    Capture

    The agent asks for one thing at a time and keeps a running transcript. No long forms, no guessing.

    Validate

    Every answer is checked against its own rule. Bad input is re-asked and logged by error code, never by content.

    Qualify

    Qualified means all five fields are valid: name, phone, email, service and a confirmed callback time. Anything less goes to review.

    Store & follow up

    Encrypted record, role-based access, a hash-chained audit trail, a signed webhook payload and a confirmation email.

    Plugs in later: voice providerLLM APICRM or Sheetsemail API. This demo simulates them so you can judge the logic first.

    03 / Vault & audit

    Same data, different eyes.
